# Student-performance-analysis-with-R
This project analyzes real-world student performance data (from UCI Machine Learning Repository) to identify statistical outliers using the Standard Deviation method.
Goals:

Import and clean raw dataset.

Calculate statistical boundaries (Mean ± 2SD) to find "Star Performers" and "Risk Groups".

Analyze the correlation between absenteeism and low performance.

Categorize and export the results for school management.

Key Insight:

Interestingly, the "Risk Group" (lowest scores) showed 0 absences, indicating that these might be administrative failures or students who didn't attend the exams at all, rather than students with chronic absenteeism.

Tech Stack: R
